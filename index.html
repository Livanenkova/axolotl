Axolotl Pro — your small but reliable assistant

It does more than just collect links:

  • Extracts external links and builds a clean References block
  • Checks statuses via proxy (with fallback 4xx/5xx check)
  • Detects duplicates and highlights redirects
  • Normalizes URLs (removes UTM, fixes ports, resolves relative links)
  • Cleans HTML from cluttered tags, inline styles, empty headings
  • Fixes headings (APA Title Case or sentence case)
  • Updates X → Twitter in both links and plain text
  • Optionally appends References back to cleaned HTML

Small but mighty — always ready to tidy up your content.
