# Axolotl Pro

**Axolotl Pro** is a lightweight internal workflow tool designed to help editorial and publishing teams validate external links and clean up HTML content at scale.

Built for multi-site digital publishing environments, it automates repetitive QA tasks and improves consistency across content operations.

## Key Features

- Extracts external links and generates a clean **References** block  
- Checks link statuses (2xx/3xx/4xx/5xx) via proxy with fallback validation  
- Detects duplicate links and highlights redirects  
- Normalizes URLs (removes UTM parameters, resolves relative links)  
- Cleans messy HTML (inline styles, unnecessary tags, empty headings)  
- Fixes heading capitalization (APA Title Case or sentence case)  
- Updates **X → Twitter** links in both anchors and plain text  
- Optionally appends References back into the cleaned HTML output  

## Purpose

Axolotl Pro was created to streamline content QA workflows, reduce manual link-checking effort, and support scalable publishing across multiple websites.
